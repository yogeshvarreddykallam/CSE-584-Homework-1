## Overview

Active learning is a machine learning paradigm where the model iteratively selects the most informative unlabeled samples to query for labels, reducing annotation cost while maintaining model performance.

This homework presents a structured critique of seminal and recent active learning papers, evaluating:

- **Query strategies** — uncertainty sampling, query-by-committee, expected model change
- **Theoretical foundations** — PAC learning bounds, sample complexity analysis
- **Empirical results** — benchmark datasets, comparison against passive learning baselines
- **Limitations** — computational overhead, cold-start problem, distribution shift
